Powerful Features for Professionals

1️⃣ Photo & Video Capture

FieldCam captures photos and videos with permanently embedded metadata:

  • Date & time (NTP / GPS / device)
  • GPS coordinates & accuracy
  • User name, category, notes
  • Watermark, logo, QR code

2️⃣ Secure QR Code Verification

Each photo includes an encrypted QR code containing verification data:

  • Cryptographic signature
  • Photo hash (SHA-256)
  • Location & time verification
  • Survives WhatsApp compression

3️⃣ Tamper Detection System

Recalculates SHA-256 hash when opening media to identify:

  • Edited images
  • Re-compressed files
  • Metadata manipulation

4️⃣ Advanced Gallery

A powerful offline gallery for data management:

  • Folder-based organization
  • Advanced search & filters
  • Batch select & export
  • Works completely offline

5️⃣ Map View & Heatmap

Visualize your project coverage:

  • Interactive location pins
  • Density heatmap view
  • Tap marker to open photo
  • Ideal for area inspections

6️⃣ Export & Reports

Generate professional documentation:

  • PDF Inspection Reports
  • KML/KMZ for Google Earth
  • CSV / TXT metadata data
  • Bulk ZIP archives
